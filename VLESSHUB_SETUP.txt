LiVPN + VLESSHub
=================

1. Установите зависимости:
   pip install -r requirements.txt

2. В .env укажите:
   PROVIDER=vlesshub

   Остальные параметры Telegram/Groq/веб-сервера оставьте как в вашей
   текущей конфигурации. UPSTREAM_URL для этого режима не нужен.

3. Запустите LiVPN:
   python run.py

При первом обновлении подписки LiVPN:
- создаст почту mail.tm;
- зарегистрирует один аккаунт VLESSHub;
- найдёт доступный пробный тариф и активирует его один раз;
- сохранит учётные данные и subscription URL в account.json;
- загрузит узлы из VLESSHub.

VLESSHub отдаёт не список vless://, а JSON-массив полных конфигов Xray.
LiVPN разбирает каждый конфиг и превращает его proxy-outbound'ы в обычные
VLESS-ссылки (поддерживаются tcp / grpc / xhttp, Reality и TLS).

При следующих запусках LiVPN использует сохранённый account.json и сначала
проверяет существующую активную подписку. Повторную активацию триала вслепую
не выполняет.

Важно:
- Не удаляйте account.json и не публикуйте его: там access token и пароли.
- Добавьте account.json в .gitignore, если проект хранится в Git.
- Один upstream-аккаунт VLESSHub используется как общий источник узлов LiVPN.
  Учитывайте лимит устройств и условия тарифа VLESSHub.
- Если хостинг имеет эфемерную файловую систему, подключите постоянный диск
  для account.json и livpn.db, иначе после пересоздания контейнера аккаунт
  не сохранится.
